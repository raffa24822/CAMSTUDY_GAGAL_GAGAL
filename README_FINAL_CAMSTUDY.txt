Deploy Render: unggah semua isi paket ke repository, Build Command: npm install, Start Command: npm start. Environment: OPENAI_API_KEY dan TEACHER_PASSWORD. Jangan taruh API key di HTML.

Fitur tambahan pada revisi ini: logo yang diberikan tertanam di HTML, pilihan ujian per kelas/semester, bank soal terpisah per semester, materi berlabel kelas/semester, avatar tambahan, dan ekspor rekap status kehadiran CSV/gambar. Materi dan file lampiran disinkronkan memakai mekanisme data portal yang sudah ada.

Catatan pengujian: validasi sintaks dilakukan lokal. Uji langsung di Render diperlukan untuk memastikan alur cloud multi-perangkat, autentikasi guru, dan penyimpanan data berjalan pada konfigurasi deploy Anda. CSV dapat dibuka di Excel; ekspor gambar berbentuk PNG.
